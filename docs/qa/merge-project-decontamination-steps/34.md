# QA 34 — BEN-34: urban project asks about decontamination in a single step

## Setup and assumptions

The e2e stack (`docker-compose.e2e.yml` + `.env.e2e`, from the repository root) must run images **built from this branch after BEN-34 was implemented**: `make e2e-up-build`. Only the `web` image changes (urban project wizard, creation and update); no migration, no new environment variable. The guide never restarts or stops a container.

- Web app / API (proxied): `http://localhost:3001`.
- Wizard pages are identified by their heading. The ones this guide relies on:
  - "Remise en état": "Le projet prévoit-il une remise en état du site ?"
  - Decontamination introduction: "Et si on dépolluait les sols ?" (text "Le site existant comporte 2 000 m² de sols pollués.")
  - **Merged decontamination step**: "Est-il nécessaire de dépolluer les sols ?" (the old "Est-il **est** nécessaire…" typo is gone)
  - Site resale introduction: "Le terrain peut faire l'objet d'une cession foncière."
  - Reinstatement expenses: the step whose form has a "Dépollution des sols" amount field.
  - Final summary: "Récapitulatif du projet".
- Before BEN-34 the urban wizard asked "Est-il est nécessaire de dépolluer les sols ?" (Oui / Non / Ne sait pas), then, for "Oui", a separate page "Quelle part des sols pollués sera dépolluée ?". The left stepper listed "Remise en état", "Choix de dépolluer" and "Surface à dépolluer" under "Travaux". The photovoltaic wizard is **not** changed by BEN-34 (it still has two pages; BEN-35 merges them).
- The merged step's URL query string is `etape=depollution-sols`; the old `etape=selection-depollution-sols` and `etape=surface-depollution-sols` no longer appear.
- The surface input mode (% / ㎡) is a global preference: switching it on one page keeps it on the next surface page.

### Reaching the merged decontamination step of an urban creation

"Reach the merged step" means:

1. Open `http://localhost:3001/creer-projet?siteId=<FRICHE_POLLUTED>`.
2. "A quelle phase du projet êtes-vous ?": pick "Montage / Développement", click "Valider".
3. "Que savez vous de votre projet ?": pick "J'ai des données précises", click "Valider".
4. Project type: pick "Autre projet d'aménagement", click "Valider".
5. Uses introduction: click "Suivant". "Quels usages offrira le projet urbain ?": pick "Espaces verts", click "Valider".
6. Spaces introduction: click "Suivant". On the surface page keep the "%" input mode (the mode is shared by every surface page of the wizard), enter `100` in "Espace végétalisé", click "Valider".
7. "Récapitulatif de l'occupation des sols": "Suivant". "Stockage du carbone par les sols après aménagement": "Suivant".
8. "2 000 m² de bâtiments seront démolis.": "Suivant".
9. "Le projet prévoit-il une remise en état du site ?": pick "Oui, le projet inclut des travaux de remise en état", click "Valider".
10. "Et si on dépolluait les sols ?" with "Le site existant comporte 2 000 m² de sols pollués.": click "Suivant".
11. Observe: the heading is "Est-il nécessaire de dépolluer les sols ?".

## S0 — The stack runs this branch

1. Run `docker compose --env-file .env.e2e -f docker-compose.e2e.yml ps` from the repository root. Observe: `web` and `api` are `running` / `healthy`, and their creation time is after the BEN-34 build.

## S1 — The merged step: title, options, stepper and URL

1. Reach the merged step (Setup).
2. Observe: the heading is "Est-il nécessaire de dépolluer les sols ?" (no "est" twice). Three radios: "Oui", "Non", "Ne sait pas" with the hint "Bénéfriches appliquera un ratio de 25% aux sols pollués.". None is selected.
3. Observe: no "Part à dépolluer" input is shown, and the next button reads "Passer" (enabled).
4. Observe the address bar: the query string contains `etape=depollution-sols`.
5. Observe the left stepper under "Travaux": exactly "Remise en état" and "Dépollution des sols"; **no** "Choix de dépolluer" nor "Surface à dépolluer". "Dépollution des sols" is the current item.

## S2 — "Oui" reveals the surface input, with max validation and % ↔ ㎡ toggle

1. On the merged step (S1), pick "Oui".
2. Observe: right below "Oui" (above "Non"), a "Part à dépolluer" input appears with the "%" / "㎡" toggle ("%" checked) and the hint "Surface contaminée : 2 000 m²". The button now reads "Valider" and is **disabled** (empty input).
3. Enter `150`. Observe: "Valider" stays disabled.
4. Replace with `60`. Observe: the hint under the input reads "💡 Soit 1 200 m²" and "Valider" is enabled.
5. Click "㎡". Observe: the input now shows `1200` and the hint reads "💡 Soit 60%".
6. Replace with `2500`. Observe: "Valider" is disabled. Replace with `1200`: "Valider" is enabled.
7. Pick "Non". Observe: the "Part à dépolluer" input disappears; the button reads "Valider" and is enabled. Pick "Ne sait pas": the input stays hidden.
8. Pick "Oui" again. Observe: the input reappears **empty** (the value typed before switching away was dropped) and "Valider" is disabled.
9. Click "%" to put the input mode back to percentage for the next scenarios.

## S3 — "Passer" records "Ne sait pas" (25 % default)

1. Reach the merged step (fresh creation: reload `http://localhost:3001/creer-projet?siteId=<FRICHE_POLLUTED>` and redo the Setup path). Don't select anything; click "Passer".
2. Observe: the heading is "Le terrain peut faire l'objet d'une cession foncière." (site resale introduction) — no "Quelle part des sols pollués sera dépolluée ?" page.
3. Click "Précédent". Observe: the heading is "Est-il nécessaire de dépolluer les sols ?" with "Ne sait pas" selected and no surface input.

## S4 — "Non" records 0 m²

1. On the merged step (continuing S3), pick "Non", click "Valider".
2. Observe: the heading is "Le terrain peut faire l'objet d'une cession foncière.".
3. Click "Précédent". Observe: "Non" is selected, no surface input.

## S5 — "Oui + surface", revisit pre-fill in the current input mode

1. On the merged step (continuing S4), pick "Oui", enter `60` (% mode), click "Valider". If a dialog "La modification de cette étape entraîne d'autres modifications." appears, click "Valider" in it.
2. Observe: the heading is "Le terrain peut faire l'objet d'une cession foncière.".
3. Click "Précédent". Observe: "Oui" is selected and "Part à dépolluer" shows `60` with "%" checked and "💡 Soit 1 200 m²".
4. Click "㎡". Observe: the input shows `1200`. Click "Précédent" then "Suivant" to come back to the merged step. Observe: "Oui" selected, "㎡" checked, input `1200`.
5. Click "%" to restore percentage mode.

## S6 — Reinstatement expenses are recomputed only when the resolved surface changes

1. On the merged step (continuing S5, "Oui" 60 % = 1 200 m²), click "Valider". Continue the creation, answering each page with its default or "Passer" / "Suivant" / "Valider" (site resale: "Non, l'aménageur restera entièrement propriétaire du site"; project developer and reinstatement contract owner: pick any structure), until the reinstatement expenses page.
2. Observe: the "Dépollution des sols" amount is `79 200` (1 200 m² × 66 €/m²). Click "Valider" without editing.
3. In the left stepper open "Travaux" → "Dépollution des sols". Pick "Ne sait pas", click "Valider".
4. Observe: a dialog "La modification de cette étape entraîne d'autres modifications." lists, under "Bénéfriches recalculera automatiquement les montants suivants :", the reinstatement expenses step. Click "Valider" in the dialog.
5. Open the reinstatement expenses step from the stepper ("Dépenses" → "Remise en état du site"). Observe: "Dépollution des sols" is now `33 000` (500 m² × 66).
6. Back to "Travaux" → "Dépollution des sols": pick "Oui", enter `25` (% mode, i.e. 500 m², the same resolved surface), click "Valider".
7. Observe: **no** dialog appears; the next page is shown directly. Open the reinstatement expenses step: "Dépollution des sols" is still `33 000`.
8. Back to "Dépollution des sols": pick "Non", click "Valider". Observe: the dialog appears again; confirm. Open the reinstatement expenses step: the "Dépollution des sols" field is no longer shown (no decontamination planned).

## S7 — Update pre-fills the merged step from the saved surface

3. Click "Travaux" → "Dépollution des sols". Observe: heading "Est-il nécessaire de dépolluer les sols ?", "Oui" selected, "Part à dépolluer" = `60` in % mode (or `1200` in ㎡ mode) and "💡 Soit 1 200 m²" (or "Soit 60%").

5. Open `http://localhost:3001/mes-projets/<URBAN_NONE>/modifier`, then "Travaux" → "Dépollution des sols". Observe: "Non" selected, no surface input. The summary's "🚧 Travaux" section reads "Travaux de dépollution: Non" with no "Surface à dépolluer" line.

## S8 — Update: change the answer and save

Note: this scenario uses the urban-zone project. On a friche, an urban project update can't be saved today, whatever the step: the update converter never pre-fills "Remise en état" (that step renders blank in update mode), so the form stays incomplete, the summary's "Valider" is disabled and answering any step lands on that blank page. This predates BEN-34 and is tracked separately.

1. Open `http://localhost:3001/mes-projets/<URBAN_ZONE>/modifier`, then "Travaux" → "Dépollution des sols".
2. Observe: "Oui" selected with `60` %. Replace the value with `30`, click "Valider" (confirm the dialog if one appears).
3. Observe: back on "Récapitulatif du projet"; "Surface à dépolluer" reads "600 m²".
4. Click "Valider" at the bottom of the summary. Observe: "Modifications sauvegardées".
5. Reload `http://localhost:3001/mes-projets/<URBAN_ZONE>/modifier`. Observe: "Surface à dépolluer: 600 m²"; the merged step shows "Oui" with `30` %.
