# 🏥 Accès aux soins

Cet indicateur reflète l’impact du projet urbain sur l’accès aux soins des riverains et/ou futurs habitants et/ou futurs actifs et usagers.

## Données utilisées dans le calcul

### Données liées au site

Aucune

### Données liées au projet

- Type de projet : urbain
- Fonctionnalité créée par le projet (Service de santé de proximité (médecin, pharmacie, laboratoire...), Etablissement hospitalier ou médico-social)

## Règles de notation

| Score             | Critère à remplir                                                   |
| ----------------- | ------------------------------------------------------------------- |
| **A_qualitative** | Au moins 2 types d'usages de santé différents prévus dans le projet |
| **B_qualitative** | Un type d'usage de santé prévu dans le projet                       |
| **C_qualitative** | -                                                                   |
| **D_qualitative** | -                                                                   |
| **E_qualitative** | -                                                                   |
