# ⚖️ Analyse coût-bénéfice

Cette vue synthétise l'ensemble des impacts agrégés en un graphique d'équilibre et détaille les effets par bénéficiaire.

Le graphique « analyse coût-bénéfice » montre, année par année, la somme cumulée de tous les impacts financiers. Il permet d'identifier le **point d'équilibre** : l'année à partir de laquelle les impacts économiques engendrés par le projet compensent le bilan de l'opération.

## Ce qui est inclus dans la courbe

- 🟦 **Bilan de développement** - décalage initial dès l'année 0. [→ Voir le détail](#bilan-de-developpement)
- 🔵 **Impacts agrégés** (statu quo inversé + projet), accumulés chaque année pour l'ensemble des acteurs. [→ Voir l'agrégation](#agregation)
- 🟢 **Bilan d'exploitation**, inclus si l'exploitant est une collectivité ou s'il est le même acteur que le développeur. [→ Voir le détail](#bilan-d-exploitation)
