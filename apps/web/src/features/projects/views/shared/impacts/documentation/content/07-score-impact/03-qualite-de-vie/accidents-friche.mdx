# 💥 Accidents sur friche

Différents sites, tels que les friches, sont souvent le théâtre d’intrusions (urbex, vols, dégradations) ou de squats qui peuvent être à l’origine d’accidents. Une simple recherche en ligne permet de recenser plusieurs dizaines de cas ces 15 dernières années.

Leur résorption permet donc de réduire les risques associés.
