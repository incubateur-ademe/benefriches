# 🏪 Accès aux services de proximité

Cet indicateur reflète l’impact du projet urbain sur l’accès aux services et commerces de proximité des riverains et/ou futurs habitants et/ou futurs actifs et usagers.

## Données utilisées dans le calcul

### Données liées au site

Aucune

### Données liées au projet

- Type de projet : urbain
- Fonctionnalité créée par le projet (services et commerces de proximité)

## Règles de notation

| Score | Critère à remplir                                      |
| ----- | ------------------------------------------------------ |
| **A** | Services ET commerces de proximité créés par le projet |
| **B** | Services OU commerces de proximité créés par le projet |
