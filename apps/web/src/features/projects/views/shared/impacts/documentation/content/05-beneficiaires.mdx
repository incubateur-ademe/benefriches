# 👥 Répartition par bénéficiaire

Les impacts sont répartis par « bénéficiaires » : ce sont les personnes ou entités directement impactées.

## 🏛️ Collectivité locale

| Impact                                                          | Signe       | Détail                |
| --------------------------------------------------------------- | ----------- | --------------------- |
| Économies friche (coûts statu quo évités)                       | ➕ Bénéfice | [↗ détail](#statuquo) |
| Recettes fiscales (droits de mutation, taxes nouvelles usages…) | ➕ Bénéfice | [↗ détail](#projet)   |
| Bénéfices d'exploitation (si exploitant = collectivité)         | ± Variable  |                       |
| Revenus locatifs nets (nouveau loyer - perte loyer actuel)      | ± Variable  |                       |
| Dépenses voirie et réseaux                                      | ➖ Coût     | [↗ détail](#projet)   |

## 🏘️ Riverains et entreprises locales

| Impact                                     | Signe       | Détail                |
| ------------------------------------------ | ----------- | --------------------- |
| Économies friche (coûts statu quo évités)  | ➕ Bénéfice | [↗ détail](#statuquo) |
| Pouvoir d'achat (mobilité, climatisation…) | ➕ Bénéfice | [↗ détail](#projet)   |
| Revenus locatifs nets                      | ± Variable  |                       |
| Hausse de la valeur patrimoniale           | ➕ Bénéfice | [↗ détail](#projet)   |
