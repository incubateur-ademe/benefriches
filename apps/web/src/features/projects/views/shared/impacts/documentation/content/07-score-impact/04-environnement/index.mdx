# 🌿 Environnement

Le score environnemental est calculé à partir des scores des sous-indicateurs suivants :

| Indicateur                                 | Détails                            |
| ------------------------------------------ | ---------------------------------- |
| ☁️ Évolution des émissions de CO2eq        | [Voir +](#emissions-de-co-eq)      |
| 🌱 Respect de l'objectif ZAN               | [Voir +](#objectif-zan)            |
| 🚰 Impacts sur la qualité de l'eau         | [Voir +](#qualite-de-l-eau)        |
| 🌾 Impacts sur la qualité des sols         | [Voir +](#qualite-des-sols)        |
| 🐸 Impacts sur les services écosystémiques | [Voir +](#services-ecosystemiques) |

## Comment le score environnemental est-il calculé ?

Les scores de chacun de ces indicateurs sont convertis en points en suivant ce tableau de correspondance

| Score | Points |
| ----- | ------ |
| A     | 90     |
| B     | 70     |
| C     | 50     |
| D     | 30     |
| E     | 10     |

Le score environnemental est la **moyenne des points des 5 sections**, arrondie à 2 décimales, ensuite reconvertie pour l'affichage en lettre en suivant [la table de correspondance point-lettre](#table-de-correspondance-point-lettre).
