# 📐 Note méthodologique : comment compare-t-on des montants dans le temps ?

Tous les impacts récurrents (qui se répètent chaque année) sont pondérés lors de leur calcul. Quatre facteurs peuvent s'appliquer selon le type d'impact :

| Facteur                           | Principe                                                                                                          |
| --------------------------------- | ----------------------------------------------------------------------------------------------------------------- |
| 📉 **Actualisation financière**   | Un euro aujourd'hui vaut plus qu'un euro dans 10 ans. On ramène tous les flux futurs à leur valeur d'aujourd'hui. |
| 📈 **Évolution du PIB**           | Certains coûts et valeurs augmentent avec la richesse produite. On corrige pour refléter cette tendance.          |
| 🌡️ **Valeur tutélaire du CO₂**    | Le prix social d'une tonne de CO₂ augmente dans le temps. Les bénéfices climatiques futurs valent donc plus.      |
| 🚘 **Émissions CO₂ par véhicule** | Les voitures deviennent progressivement moins polluantes. On tient compte de cette amélioration attendue.         |

> 📌 **Conventions de signe :** dans tous les tableaux, un montant **positif (+)** représente un bénéfice, un revenu ou un coût évité ; un montant **négatif (-)** représente une dépense ou une perte.
