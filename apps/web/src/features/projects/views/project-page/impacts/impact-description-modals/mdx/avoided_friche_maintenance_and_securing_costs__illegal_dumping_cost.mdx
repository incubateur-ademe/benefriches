## Quelles données sont utilisées dans le calcul ?

### Données systémiques agrégées par Bénéfriches :

- Ratio moyen de production de déchets retrouvés dans les dépôts sauvages 4.7 kg/habitant/an
- Coût moyen de gestion (enlèvement, traitement) des déchets de dépôts sauvages : 900 €/tonne
- _Population communale_

## Comment est fait le calcul ?

_Le calcul consiste à multiplier le ratio de production de déchets retrouvés dans les dépôts sauvages par le coût moyen de gestion de ces déchets. Le site ne pouvant être le seul lieu de dépôts sauvages de la commune, un facteur d’occurrence est appliqué (estimé égal à 1/50)._
