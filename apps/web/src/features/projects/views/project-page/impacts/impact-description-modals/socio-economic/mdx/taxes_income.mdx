La concrétisation du projet va générer des recettes fiscales pour la collectivité, variables selon le type de projet et/ou la catégories d’utilisateurs :

- exemples de taxes locales pour les entreprises : cotisation foncière des entreprises (CFE), taxe foncière sur les propriétés bâties (TFPB), taxe foncière sur les propriétés non bâties (TFPNB) ou encore taxe sur les surfaces commerciales (TaSCom);
- pour les projets photovoltaïques : imposition forfaitaire des entreprises de réseaux (IFER);
- exemple de taxes locales pour les particuliers : taxe foncière

**Bénéficiaire** : Collectivité

## Comment est fait le calcul ?

_Le total des recettes fiscales escomptées en une année est la somme des recettes attendues, selon l’usage futur prévu en projet, pour chacune des fonctions suivantes : logement, activités économiques, photovoltaïque._

- Pour le logement, les recettes fiscales sont le produit de la surface totale de logement prévus (*exprimée en m² SDP) par le montant de la f*iscalité locale moyenne du logement (exprimé en €/m²SDP/an).
- Pour les activités économiques (hors photovoltaïque) les recettes fiscales sont le produit du nombre d’emplois prévus *par le montant de la f*iscalité locale moyenne des entreprises (exprimée en €/salarié/an). Si le nombre d’emploi n’est pas connu, BENEFRICHES le calcule par application de ratio d’occupation par salarié par type d’activités distinguant les activités tertiaires (bureaux, administration, enseignements) des autres activités (commerce, artisanat, industrie) (exprimés en m²SDP/salarié) à la surface d’activités économiques prévue, ventilée par type d’activité (_exprimée en m² SDP)._
- Pour le photovoltaïque, les recettes fiscales sont le produit du montant de la fiscalité locale moyenne (exprimée en €/kWc/an) pour cette activité par la puissance installée (exprimée en kWc).
